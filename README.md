# Nightmare Bridge

The public doorway to the eCAW (Ethereum) → cqCAW (QL1) one-way migration bridge, in the nightmare world: one black page, blood-red type.

**Live (this stub):** https://ql1-infinite42-guppy-histoire.github.io/nightmare/

> WILL YOU SEE A NIGHTMARE, OR…? IT DEPENDS ON THE COMMUNITY'S ACTIONS…

This GitHub Pages site is now only a stub. The full bridge page no longer lives here: it is served by a Cloudflare Worker at https://nightmare-bridge.nepicobsv.workers.dev behind a password gate. The page content is not sent to the browser until the password matches — the check happens on the server side, so the route, the terms and the addresses on the bridge page are not visible to anyone who does not know the password. The password is set by the owner through a one-time setup page; it is not in this repository.

**Status: NOT OPERATING.** The bridge is not live. The page behind the gate says so plainly: the contracts are built but not yet deployed, migration has not started, and its deposit panel is a disabled preview that connects to no wallet and moves no funds.

Developed by the community. Not an official site.
